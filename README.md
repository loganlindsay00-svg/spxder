# Spxder Signals

Consistency hybrid for MNQ / NQ / ES.

## Rules
1. Higher-timeframe bias required
2. Killzone only (London / NY AM)
3. Liquidity sweep required
4. Mean-reversion / equilibrium entry
5. All steps must pass or NO TRADE

Default risk: $250 per trade.

## Deploy on Streamlit Cloud
Upload to repo root:
- app.py
- requirements.txt

Main file path: `app.py`

## Local
```
pip install -r requirements.txt
streamlit run app.py
```
